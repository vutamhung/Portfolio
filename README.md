# Vũ Tam Hưng – Video Editor Portfolio

Trang portfolio một trang (HTML/CSS/JS thuần, không cần build) của Vũ Tam Hưng, Video Editor tại Hà Nội.

- `index.html`: toàn bộ trang (ảnh chân dung nhúng sẵn dạng base64).
- `media/`: video đã nén (H.264, 480–720p, mỗi file < 15 MB), ảnh poster và ảnh minh hoạ dịch vụ.

Xem thử: mở `index.html` bằng trình duyệt, hoặc bật GitHub Pages cho nhánh `main`.

Ảnh minh hoạ trong `media/sv/s-*.webp` lấy từ [Unsplash](https://unsplash.com) (Unsplash License).
